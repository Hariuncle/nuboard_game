# Acorn Bomber runtime asset slot

Place the final optimized model here with this exact filename:

`AcornBomber_Optimized.fbx`

Unity exposes it through the Resources key
`Meshy/AcornBomber/AcornBomber_Optimized`, which is the first path checked by
`OptionalEnemyModelAdapter`. Keep this README; it does not affect runtime asset
loading and lets the fallback path remain documented before the binary arrives.
