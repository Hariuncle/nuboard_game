# NEON BREACH 이동 에임·효과음·스토리 인트로 설계

## 목표

기존의 중앙 고정 조준점과 이동하는 월드 표현을, 고정된 전장 위에서 조준점만 화면 전체를 이동하는 방식으로 바꾼다. 동시에 무음 게임에 즉각적인 합성 효과음을 추가하고, 현재 2.33초 단일 H3 캐릭터 영상은 이야기와 게임 전환을 가진 약 7초짜리 3막 인트로로 교체한다.

## 플레이 조작

- 전장 배경과 드론은 정규화된 고정 화면 좌표에 렌더링한다.
- BLE HID 마우스, 일반 마우스의 상대 이동, 모바일 터치 드래그는 모두 하나의 `aim` 좌표를 갱신한다.
- 조준점은 화면 전체를 이동하되 원과 십자선이 잘리지 않도록 시각 반경만큼 가장자리 안쪽에서 제한한다.
- Pointer Lock 성공 시 `movementX/Y`, 실패 시 보이는 커서의 캔버스 좌표를 사용한다.
- 방아쇠 또는 왼쪽 클릭은 현재 조준점 좌표로 발사한다.
- 명중 판정은 화면 종횡비를 반영한 드론의 실제 렌더 반경과 일치한다. 화면 경계 반대편으로 감싸는 판정은 사용하지 않는다.
- 키보드 게임 입력은 추가하지 않는다.

## 사운드

별도 음원 다운로드 없이 Web Audio API로 짧은 합성 효과음을 만든다. 첫 시작 클릭이나 BLE 방아쇠 입력에서 `AudioContext`를 재개해 브라우저 자동재생 제한을 지킨다.

- 발사: 짧은 노이즈와 하강하는 에너지 펄스
- 명중: 밝은 고주파 확인음
- 빗나감: 낮고 짧은 오류음
- 보스 등장: 이중 경고 펄스
- 승리: 상승하는 3음
- 패배: 하강하는 3음

효과음은 게임 상태를 바꾸지 않으며 오디오 초기화 실패 시에도 플레이는 계속된다. 빠른 연속 발사에서도 긴 노드가 누적되지 않도록 각 음은 짧게 종료한다.

## 3막 인트로

최종 영상은 1344×768, 24fps, H.264 MP4이며 약 7초다. KT AI Nexus의 H3 ComfyUI를 공식 Comfy MCP/API로 실행해 56프레임 장면 세 개를 만들고 이어 붙인다.

### 1막 — 침입 감지

정전된 네온 훈련장에 붉은 경보가 켜지고 오버시어 드론들이 활성화된다. 자막은 `훈련망 침입 감지`다. 기존 `neon-arena.png`와 `overseer-drone.png`를 시각 기준으로 사용한다.

### 2막 — RIN 통신

통신 노이즈 뒤 RIN이 화면에 등장한다. 자막은 `오버시어가 훈련망을 장악했다`다. 기존 RIN 캐릭터의 얼굴, 헤어, 바이저, 슈트 정체성을 유지한다.

### 3막 — BREACH

RIN이 총을 들어 카메라를 조준하고, 바이저의 시안 원형 HUD가 화면을 덮으며 게임의 1인칭 전장으로 전환된다. 자막은 `조준 링크 연결 — BREACH`다.

자막과 장면 전환은 브라우저 DOM이 아니라 최종 영상에 합성해 어떤 재생 환경에서도 동일하게 보이게 한다. 인트로 종료·건너뛰기·재생 실패는 모두 같은 게임 시작 함수로 연결한다.

## 구성 요소

- `game/src/aim.mjs`: 조준 이동, 가장자리 제한, 화면 좌표 변환의 순수 함수
- `game/src/sfx.mjs`: Web Audio 초기화와 게임 효과음 재생
- `game/src/game.mjs`: 입력을 aim 모듈로 전달하고 상태 변화에 맞춰 효과음을 호출
- `game/src/engine.mjs`: 고정 화면 좌표 기반 명중 판정
- `game/assets/video/h3-rin-story-intro.mp4`: 새 3막 인트로
- `game/assets/video/h3-rin-intro.mp4`: 새 영상 생성 전까지 유지되는 기존 fallback

## 데이터 흐름

총의 자이로 또는 포인터 이동 → aim 모듈 → 제한된 정규화 좌표 → 이동한 조준점 렌더 → 방아쇠 클릭 → 엔진 `fireAt` → 명중/빗나감 상태 → sfx 모듈 효과음 및 HUD 갱신 순서다. 배경 좌표는 aim 변화의 영향을 받지 않는다.

인트로는 ImageGen 기준 이미지 → KT 입력 전송 → 장면별 H3 MCP 검증/실행/수집 → MP4 연결·자막·전환 합성 → 로컬 게임 자산 교체 순서다.

## 오류 처리

- Pointer Lock 거절 시 보이는 커서 조준을 유지한다.
- Web Audio 미지원 또는 정지 상태에서는 무음으로 계속한다.
- H3 영상 로딩 실패 시 기존 포스터 fallback 뒤 게임을 시작한다.
- 장면별 H3 생성 실패 시 성공한 장면을 보존하고 실패한 장면만 다시 생성한다.

## 검증 기준

- 조준 이동 중 배경과 드론의 화면 좌표가 변하지 않는다.
- 조준점이 모든 화면 가장자리까지 이동하지만 시각 요소가 잘리지 않는다.
- BLE HID 마우스 이동과 왼쪽 클릭만으로 시작, 조준, 발사, 결과, 재시작이 가능하다.
- 모바일 드래그와 탭이 같은 좌표·발사 경로를 사용한다.
- 키보드 이벤트 리스너가 없다.
- 발사, 명중, 빗나감, 보스, 승리, 패배 효과음 호출이 상태와 일치한다.
- 새 영상은 1344×768, 24fps이며 세 장면과 세 자막이 순서대로 포함된다.
- 인트로 재생 후 자동으로 게임이 시작되고 브라우저 console error가 없다.
- 순수 로직 테스트, 모듈 구문 검사, 데스크톱 및 모바일 브라우저 검증을 통과한다.

## 범위 밖

배경 음악, 음성 더빙, Web Bluetooth 전용 GATT 프로토콜, 3D 엔진 전환, 키보드 조작은 이번 변경에 포함하지 않는다.
