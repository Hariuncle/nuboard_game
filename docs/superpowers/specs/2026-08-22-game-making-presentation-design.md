# BLOSSOM BREACH 제작 과정 발표 자료 설계

## 목적과 대상

게임을 처음 보는 교사·동료에게 BLOSSOM BREACH가 어떤 도구와 흐름으로 제작되었는지 3장의 PowerPoint로 설명한다. 세부 코드보다 이미지와 제작 순서를 우선한다.

## 슬라이드 구성

1. **아이디어를 이미지로** — Codex의 ImageGen으로 세계관, 캐릭터, 배경 콘셉트 이미지를 만들고 시각 방향을 정한 과정을 보여준다.
2. **이미지를 플레이 가능한 게임으로** — Unity MCP를 활용해 작업을 연결하고, 3D 에셋 제작·배치, 게임 로직 구현, 캐릭터 애니메이션 적용 과정을 설명한다.
3. **움직이는 이야기로 완성** — H3로 인트로 영상을 제작하고 Unity 게임과 결합해 최종 플레이 경험을 완성한 흐름을 요약한다.

## 시각 원칙

- 16:9 화면비, 밝고 부드러운 게임 아트의 색감을 사용한다.
- 각 장은 큰 이미지 한 장 또는 두 장을 중심으로 하고, 본문은 발표용 핵심 문장 2~3개로 제한한다.
- ImageGen 콘셉트 시트, 3D/Unity 제작 화면, H3 영상 프레임을 서로 다른 장에 배치한다.
- 기술명은 `Codex ImageGen`, `Unity MCP`, `H3`로 통일한다.

## 완료 기준

- 정확히 3장이다.
- 사용자가 지정한 네 가지 내용(ImageGen, H3 영상, Unity MCP, 3D 에셋과 애니메이션)이 모두 명시된다.
- 각 장에 관련 이미지가 포함되고, 텍스트가 잘리거나 겹치지 않는다.
- 최종 PPTX를 렌더링해 모든 슬라이드를 육안 검수한다.
